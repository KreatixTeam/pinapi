pinapi / unofficial pinterest api

pinapi

Unofficial REST API for Pinterest, in Rust. Read endpoints are public — no key needed. Writes and personal endpoints require Authorization: Bearer <key>. Responses are slimmed to the essentials; send x-raw: 1 for full upstream payloads. Rate limit: 60 req/min per IP.

quick start
curl -s "https://pinapi.kreatix.dev/v1/search?q=interior%20design&scope=pins&page_size=3"
